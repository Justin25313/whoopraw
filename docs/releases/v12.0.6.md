# WhoopRaw 12.0.6

- On iPhone, pull down at the top of Today and release to request synchronization through the native iOS refresh control. It also works when the dashboard is shorter than the screen.
- Each recognized refresh gives a light haptic and visible feedback. Offline and already-syncing states no longer silently suppress the gesture.
- A connected band still finishing its pairing handshake keeps the request through the existing pending-sync path. A ready band uses the existing manual synchronization entry point; running offloads are reused.
- The white band app icon from 12.0.5 is retained.

The application identity, widget and on-device data formats are retained. Bluetooth protocol commands and score calculations are unchanged. The simulator check establishes gesture recognition and feedback, not physical haptics or successful data transfer from a real WHOOP band.

Validation: all 17 GitHub checks passed on product source `c35ef7aac17edfae14d8f226398d56c1e25e591b`, including the iOS build and 2,280 macOS app tests (2 skipped, 0 failures). Four app tests cover sync-request dispatch, offline safety, pairing and running-sync reuse. The native iPhone simulator test passed short-drag rejection and two deliberate pull gestures reaching the real refresh callback and offline feedback; no physical strap was simulated.
