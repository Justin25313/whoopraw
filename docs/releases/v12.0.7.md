# WhoopRaw 12.0.7

- WHOOP 4 uses the existing family-specific manual battery read once per connection, after the handshake and command-reply notifications are confirmed. A running history transfer postpones this read without consuming it; offload completion retries the readiness gate. Disconnect resets the one-shot gate. WHOOP 5/MG keeps its existing battery path.
- A first received live battery percentage is recorded locally so on-device verification can distinguish a requested read from a received result.
- Tapping Today opens a graphical calendar with a 320-point minimum width and 360-point minimum height. Selecting a date still uses the existing logical-day binding and dismissal.
- Pull-to-sync feedback now sits in the normal layout beneath WhoopRaw instead of overlaying the header. Profile, date and band controls remain unobstructed. The native pull gesture and light haptic are retained.

Application and widget identities, data formats, imports and scoring are unchanged. This Apple connection-readiness fix does not change decoding, stored values, command payloads or Android behavior. The battery request reuses the existing read-only command; its new automatic timing needs confirmation on a physical WHOOP 4. Simulator validation cannot establish Bluetooth data transfer or physical haptics.

Validation: all 17 GitHub checks passed on product source `e41ed31690455e89f067825263738c258df40e14`, including both Apple builds and 2,284 macOS app tests (2 skipped, 0 failures). Four new tests cover readiness callback order, offload deferral, duplicate suppression and connection reset. The native iPhone calendar interaction test passed full-size display, date selection and dismissal. A real native pull produced the offline sync callback and a captured localized message below the unobstructed header; its immutable accessibility capture passed label and placement checks. The UI harness later failed by querying the six-second message after saving the capture, when it had expired; this test timing is being corrected separately. No physical strap was simulated.
