# WhoopRaw 12.0.5

- The iPhone primary and alternate app icons, and all Mac app-icon sizes, now use the selected white band artwork on black.
- Pull down at the top of Today to fill the progress ring. Crossing the 80-point threshold produces a light haptic tick on iPhone; releasing requests the existing manual strap-history sync.
- A running sync is reused rather than started again. The ring measures the pull gesture, not downloaded-history percentage; ongoing history progress remains on the Devices screen.

The application identity, widget extension and on-device data formats remain compatible with 12.0.4. Bluetooth protocol commands and score calculations are unchanged. This update does not claim to resolve a stalled Bluetooth connection or missing current-day scores.

Validation: all 17 GitHub checks passed on the product-source commit `86ed122dc12ad9ff702b1831b3aad30dbb5104c3`, including the iOS app build and macOS app build/tests. Twelve opaque app-icon slots passed format and size verification. Physical iPhone pull gestures, haptics and strap synchronization remain unverified.
